# Nail-lounge
Sitio web de manicurista, servicio de reservas.

- `index.html`: página pública (servicios, precios, reservas por texto, reseñas, FAQ y Estilista IA de uñas).
- `worker.js`: backend en Cloudflare Workers (`nailsia`).
- `app/`: app de administrador instalable ("Citas").

Paleta: Ivory `#F7EFE7` · Mocha `#6B4E3F` · Dusty pink `#D9A6A5` · Light beige `#E1D2C4`.
Instrucciones de instalación en `LEEME.txt`.
